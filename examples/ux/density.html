Density

Same dashboard data, three rhythms. The token deltas are padding, font sizes, and gap values — no structural change. Choose what feels right for the kinds of dashboards you build most.

2026 trend: ship a density toggle (Sprinklr, Salesforce, MUI all do). User picks once, persists.

A1 · Compact ↗ fullscreen
Pros More data per screen · Power-user feel · Less scrolling on logs/tables
Cons Tighter touch targets · Harder for casual scans · Looks "intense"
A2 · Comfortable (current default) ↗ fullscreen
Pros Balanced rhythm · Good for mixed audiences · 44px touch targets
Cons Compromise: not the densest, not the calmest
A3 · Spacious ↗ fullscreen
Pros Calm scan · Marketing-grade feel · Hero metrics breathe
Cons More scrolling · Less data per screen · Phones suffer

If you adopt this

Add data-density attribute support to glacial.css with compact, comfortable (default, no overrides needed), and spacious values. Persist user choice in cookie glacial-density, mirror the theme/skin pattern. Add window.glacialSetDensity(name).

You can also pick one as the new default. If you primarily build infra dashboards, "compact" might just be the new comfortable. If you build personal/lifestyle apps, "spacious" might fit better. The toggle is most useful when you have apps that span the range.
