The thin wrapper reads the live theme/skin/aesthetic off <html> and appends them, omitting any value that equals the destination default. It merges with an existing query, keeps params before a #hash, overwrites a conflicting param, and is idempotent.

Opt-in config (set before glacial.js loads)

Window global or a <meta> with the same kebab-case name. All default off/unset: 

<script>
  window.GLACIAL_SHARED_THEME  = true;        // one glacial-theme cookie + persist carried params
  window.GLACIAL_DEFAULT_THEME = 'auto';      // follow OS preference
  window.GLACIAL_DEFAULT_SKIN  = 'deep-navy'; // durable default skin (pre-paint, no FOUC)
</script>

With GLACIAL_SHARED_THEME on, a carried-in param is validated against glacial’s vocab and persisted to this surface’s host-only cookie, so a later cold reload keeps the carried look. Off-vocab values are ignored (no cookie poisoning). v2.6’s GLACIAL_COOKIE_DOMAIN was removed (single-label-TLD cookies are rejected by browsers).
