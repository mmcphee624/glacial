How it works

Each frame loads dashboard.html?skin={name}. URL parameters override cookies for that page load, so the iframes don’t conflict with your top-level skin choice. Theme is set on each iframe’s <html> via data-theme when you change the theme selector. The skins themselves are pure CSS — same markup, different tokens.

Authoring a new skin: copy skins/_template.css, fill in token overrides, link it after glacial.css, and set <html data-skin="your-name">. The skin contract (token-only, no class-internal selectors) is enforced by scripts/lint-skin.sh.
